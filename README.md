# What the project is about
Zentrix is an interactive educational website that reveals how digital cameras turn incomplete color information into full-color photographs.
Most digital cameras use a technology called a Bayer filter, where each sensor pixel captures only one color: red, green or blue.
The camera then uses a process called demosaicing to estimate the missing color information and reconstruct the final image.
Zentrix allows users to:
Explore how Bayer filters capture color information.
Understand how demosaicing works.
Compare different image reconstruction algorithms.
See how false colors and visual artifacts can appear.
Upload their own photographs and experiment with reconstruction.
The main purpose of Zentrix is to make an invisible technology visible and interactive, helping people understand what actually happens inside the cameras they use every day.

# Who is it for
Zentrix is designed for Students and learners, photography enthusiasts, aspiring developers, teachers and educators.
